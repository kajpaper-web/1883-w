# 1883 Watchlist

A personal episode checklist for the TV series **1883** (the Yellowstone prequel).

- 10 episodes with Persian and English titles, air dates and runtimes
- Tap an episode to tick it — ticks are saved in the browser's localStorage on your own device
- Progress bar, next-episode panel, check-all and reset controls
- No login, no tracking, no external requests — a single self-contained HTML page

Open `index.html` in Safari on iPhone, then **Share → Add to Home Screen**.
